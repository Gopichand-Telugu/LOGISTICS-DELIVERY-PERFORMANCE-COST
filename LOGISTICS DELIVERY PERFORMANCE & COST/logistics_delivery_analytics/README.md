# Logistics Delivery Analytics

An end-to-end Python project for cleaning, exploring, and monitoring order delivery performance and shipping costs.

## Project layout

```text
logistics_delivery_analytics/
|-- data/
|   |-- raw/logistics_data.csv
|   `-- cleaned/logistics_cleaned.csv  # generated by the pipeline
|-- notebooks/logistics_analysis.ipynb
|-- src/                               # loading, cleaning, analysis, charts
|-- app/streamlit_app.py
|-- reports/business_report.md         # generated by the pipeline
|-- tests/test_pipeline.py
|-- run_pipeline.py
|-- requirements.txt
`-- README.md
```

## Setup

Open a terminal in this folder and run:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run `.venv\Scripts\python.exe -m pip install -r requirements.txt` and use `.venv\Scripts\python.exe` in the commands below.

## Run the data pipeline

```powershell
python run_pipeline.py
```

This reads `data/raw/logistics_data.csv`, writes the cleaned dataset to `data/cleaned/logistics_cleaned.csv`, and generates `reports/business_report.md`.

## Open the dashboard

```powershell
streamlit run app/streamlit_app.py
```

The dashboard supports filters for order date, shipping mode, delivery partner, and timeliness. It shows on-time delivery, shipping spend, ratings, partner and mode comparisons, cost by route distance, and filtered order detail.

## Explore and test

Open `notebooks/logistics_analysis.ipynb` in Jupyter or VS Code. Run the test suite with:

```powershell
python -m pytest
```

## Metric definitions and data handling

- On time means `actual_delivery_date <= expected_delivery_date`; it is calculated independently of the source status label.
- Delay is the non-negative number of calendar days past the expected date.
- Tracked total cost is recorded shipping cost plus recorded fuel cost. Verify that fuel is not already included in shipping charges before treating this sum as an accounting total.
- Exact duplicate rows are removed. Missing fuel cost uses the median within shipping mode and then the overall median. Missing shipping costs, destination cities, ratings, and warehouse processing hours stay missing.
- Delivery partner and shipping mode comparisons are descriptive, not adjusted for route mix, distance, or package characteristics.
